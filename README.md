# Horário EPALC (piloto)

App web com o horário semanal das turmas da EPALC – Escola Profissional António do Lago Cerqueira.

- `index.html` – a app (telemóvel e computador). Lê os dados de `horario.json`.
- `horario.json` – horário da semana. Atualizado todas as sextas-feiras a partir do horário enviado pela secretaria.

Versão piloto: só a turma 2-PI02. O objetivo é passar a ler os dados diretamente da API do e-Schooling.
